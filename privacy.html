morning-brief privacy policy

Last updated 22 November 2026

morning-brief is a personal, single-owner tool. This page explains what data it accesses and what it does with it.

Data it accesses

  • Gmail (scope gmail.readonly): subject, sender, date, a short preview, and list headers of new messages in the owner's own accounts.
  • Google Calendar (if enabled): free/busy times, and meetings the owner explicitly approves creating.

How it is used

  • To build the owner's daily summary and, on the owner's request, to find meeting times.
  • Message subjects, senders and previews are sent to the Google Gemini API to rank them by importance. They are not sent to anyone else.
  • The data is not sold, not used for advertising, and not used to train AI models.

Storage

  • Sign-in tokens and recent summaries are stored only on the owner's own server, in files readable only by the owner.
  • Past summaries are kept as plain files so the owner can look back. The owner can delete them at any time.

Google API Services User Data Policy

morning-brief's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/connections. Removing it stops all further reads immediately.

Contact

Questions go to the support email shown on Google's sign-in screen for this app.
